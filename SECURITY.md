# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them
privately through GitHub instead:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/nbomers/movienight/security/advisories/new)).

Include what you found, how to reproduce it and which version or commit you
tested. You will get an answer within a week. Once a fix is released, the
advisory is published with credit to you, unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
